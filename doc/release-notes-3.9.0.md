# v3.9.0 发布说明

> 版本 **3.9.0** / versionCode **191**（arm64-v8a 包 191003、armeabi-v7a 包 191001）
> Android 16（targetSdk 36），`minSdk 21`，ABI：`arm64-v8a` + `armeabi-v7a`。

本版包含两大部分：**阶段 U 的 UI/动效系统化重构** 与 **本地音乐管理与播放 2.0**。

---

## 本地音乐管理与播放 2.0

### 曲库与浏览
- 新增派生索引层：专辑 / 艺人 / 文件夹 / 最近添加 / 聚合封面一次构建并持久化，冷启动直接出首屏。
- 专辑、艺人页签改为 **3 列网格**，封面按组聚合，不再固定取第一首。
- 排序：歌名 / 歌手 / 专辑 / 时长 / 添加时间 / 文件路径，升降序，按页签记忆。
- 筛选：格式（FLAC/MP3/M4A/WAV/OGG/APE）、有无封面；筛选时页头仍显示完整曲库数。
- 搜索扩展到 **文件名 / 路径 / 拼音首字母**。
- 工具条新增「选择」批量模式：勾选后加入队列 / 添加到歌单 / 隐藏 / 从曲库移除。

### 扫描与曲库健康
- 增量扫描：路径 + mtime + size 未变化的文件直接复用旧条目，不再重复读标签。
- 扫描报告：新增/更新/未变化/移除/失败统计；主页 banner + 扫描面板摘要 + 详情弹窗。
- 本地文件丢失时恢复队列会向后找第一首有效歌，避免启动播放失败。
- 隐藏歌曲 / 隐藏文件夹（不删文件），设置 → 音乐工具 → 隐藏内容可恢复。
- APE / WMA / DSF / DFF 在列表标「可能不支持」（不阻止尝试播放）。

### 播放与工具
- 播放倍速 0.5×～2.0×，切歌/重启保持。
- 切歌淡入淡出 0/2/4/6/8/12 秒（淡出→切→淡入，暂停时强制恢复音量）。
- 队列/进度持久化：暂停、退后台、切歌立即落盘；冷启动恢复队列和暂停点。
- M3U/M3U8 导入导出：路径 → 文件名 → 歌名+歌手+时长三级匹配。
- 本地歌词：内嵌歌词优先，缺失时读同目录同名 `.lrc`；新增歌词偏移（±0.5s / ±0.1s / 0）。

## 阶段 U：UI/动效

- 液态琉璃悬浮栏（胶囊 / 迷你播放器 / 子页播放条统一玻璃层，三档：液态/毛玻璃/关闭）。
- 首页听歌统计卡片（今日/本周/7 日/常听歌曲/艺人）。
- 排行榜/歌单详情/搜索长按统一多选 + ActionSheet；搜索多选栏改悬浮胶囊。
- 歌词设置收敛为播放器单入口 + 竖向快捷图标菜单。
- 定时关闭（15/30/45/60/90 分或播完当前曲）。
- 弹性进度条（可拖动、越界回弹、无障碍 ±5%）。
- 本地音乐 A-Z 首字母筛选、下拉扫描、搜索入口迁移。
- 转场横屏支持、共享元素强化、减少动态效果（系统无障碍同步）。
- 统一 Skeleton / 三态容器 / 关键页面无障碍标签；液态玻璃去掉竖向接缝。
- LOGO 换新（白色圆角底 + 居中音符 + 紫色弧线）。

## 已知限制 / NOT RUN

- 淡入淡出、倍速实际听感需真机确认；杀进程恢复队列/进度、M3U 实际选文件往返、同名 `.lrc` 与歌词偏移 UI 尚未逐项真机验收。
- 重复歌曲清理只移除曲库记录，暂未迁移收藏/歌单引用。
- 批量「移除」只移曲库，未删除文件/回收目录。
- 淡入淡出是「淡出→切→淡入」，不是双播放器真 crossfade。
- content:// 曲目暂不支持同目录 `.lrc` 回退。
- 10k 曲库性能压测待 P0-04/P0-05 前置完成后补。
