# v3.9.3 修复发布说明

> 版本 **3.9.3** / versionCode **194**（arm64-v8a 包 194003、armeabi-v7a 包 194001）

本版修复三个用户反馈问题。

## 1. 冷启动后首次播放卡住 / 自动切歌
- 根因：启动恢复与手动播放共用 `restorePlayInfo`，手动点歌被当成“恢复”；恢复后还有 5 秒轮询 `pause`，会打断首次播放。
- 修复：
  - `handlePlay(isRestore)` 显式区分启动恢复与普通播放；
  - 手动播放清空残留恢复标记；
  - 移除恢复后的轮询暂停（插件已在恢复分支保证暂停）。
- 验证：冷启动后点首页歌曲 → PLAYING；暂停/继续后进度继续推进。

## 2. 首页 5 卡动效与铺排
- 5 张卡从横向轮播改为 **3 列 + 2 列居中** 铺排；
- 左右 16dp、列间距 10dp，卡片宽高按视口动态计算；
- 恢复排行榜柱状、歌单唱片、收藏爱心、音源波纹、统计卡呼吸；
- 新增设置 **设置 → 基本设置 → 界面 → 首页卡片动效**。

## 3. 专辑封面自转
- 新增设置 **设置 → 基本设置 → 界面 → 专辑封面自转**；
- 胶囊任务栏 / 迷你播放器共用 `AlbumDiscSpin`，开关同时生效；
- 测试设备的系统动画缩放此前为 0，已恢复为 1；若设备仍关闭系统动画，部分原生动画可能仍受限。
