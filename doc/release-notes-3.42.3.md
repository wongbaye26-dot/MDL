# EmoMusic v3.42.3 发布说明

发布日期：2026-11-09

## 变更

### 空闲动画节能

首页大卡片上的常驻装饰动效（跳动柱状 / 黑胶自转 / 爱心 / 波纹 / 统计呼吸）此前会一直 60fps 运行，
是首页空闲时 CPU 的主要来源。现在：

- 只在「首页为当前 Tab + App 在前台 + 最近 8 秒有触摸/滚动」时运行；
- 空闲 8 秒自动停止，用户一碰屏幕/滚动，1 秒内恢复；
- 切到其它 Tab、进入播放器、App 退到后台立即停止。

### 其他

- 胶囊进度环「呼吸」只在播放中运行（暂停后不再空转 60fps）。
- 玻璃模糊：长时间无滚动（>2.5s）后快照刷新降到 0.5fps，滚动立即恢复高频。

## 实测（SM-S938B / Android 17）

| 场景 | 指标 | 优化前 | 优化后 |
|---|---|---|---|
| 暂停播放 + 首页空闲 | RenderThread | ~45% | **0%** |
| 暂停播放 + 首页空闲 | 进程 CPU | ~66% | **3.7%** |
| 播放中 + 首页空闲 | RenderThread | ~45% | ~25%（只剩胶囊圆盘自转） |

触摸首页后 RenderThread 恢复到 50% 左右（装饰动画恢复），属预期。
