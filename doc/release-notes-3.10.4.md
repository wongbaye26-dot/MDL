# v3.10.4 发布说明

> 版本 **3.10.4** / versionCode **224**

## 后台/锁屏自动切歌无声（严重修复）
根因：切歌淡入淡出在后台/锁屏时执行：
1. `fadeVolumeTo(0)` 把音量降到 0；
2. 新歌起播后靠 `setTimeout(350ms)` + JS sleep 逐级升回；
3. 后台 JS 定时器被系统挂起，音量永久停在 0。

表现：UI 时间/进度/歌词都正常推进，但完全没有声音；回前台后部分场景才恢复。

修复：
- 后台/锁屏切歌**跳过淡入淡出**，直接 `restoreVolume()`；
- 淡入回调执行时若发现已不在前台，也立即恢复音量；
- AppState 回到 active 时，若 `isPlay` 且音量≈0，兜底恢复用户音量。
