# EmoMusic v3.11.12 发行说明

> 版本 **3.11.12** / versionCode **260**

## 本地搜索交互修复
- 搜索从全屏 Modal 改为页内悬浮栏，不再用透明遮罩盖住结果列表；
- 修复搜索结果不能点击播放（点击被遮罩吃掉）；
- 修复上下滑动结果列表会自动退出搜索（滑动结束触发遮罩关闭）；
- 歌手/专辑候选胶囊不再被 flex 压缩截断。
