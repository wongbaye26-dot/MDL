# v3.10.6 发布说明

> 版本 **3.10.6** / versionCode **226**

## 桌面小组件升级
### 2×2
- 专辑封面改为**铺满整张卡片**（本地封面裁圆角位图）；
- 底部渐变遮罩上显示歌名/歌手；
- 控制：上一首 / 播放暂停 / 下一首。

### 4×1
- 对齐迷你播放器：封面 + 歌名/歌手 + 上一首/播放暂停/下一首；
- 深色圆角玻璃底。

### 明暗主题
- JS 把 `themeState.theme.isDark` 传给原生；
- 小组件背景、标题/副标题文字、按钮底、2×2 渐变遮罩分暗/亮两套；
- 主题切换时（`themeUpdated`）自动刷新。
- 播放/暂停/下一首/上一首通过媒体按键广播控制；点击卡片打开应用。

## 拖动进度条偶发从头播放
- seek 后 900ms 内屏蔽进度轮询回写；
- 650ms 后若目标进度未被竞态覆盖，补一次 `seekTo`；
- 起播时清除保护窗口。
防止起播/换源回调把用户拖动后的进度重置到 0。
