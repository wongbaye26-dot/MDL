# EmoMusic v3.51.0 发布说明

发布日期：2026-11-09

## 新增 / 改进

### 下载中心多选管理（新）

- 顶部新增「选择」入口，或**长按任务**直接进入批量模式；
- 批量操作：
  - **全选 / 反选**（按当前列表）；
  - **暂停**：暂停所选正在下载的任务；
  - **继续**：开始/重试所选未完成任务；
  - **移除**：只移除任务记录，不删已下载文件（带确认弹窗）；
  - **删文件**：删除所选「已完成」任务的文件 + 记录（危险确认）；
  - 底部操作条实时显示「已选 N」，操作完成后自动退出批量模式。
- 与本地音乐列表共用同一套交互语言（勾选圈、底部操作条），单任务原有 ⋮ 菜单保留。

### 本地音乐二级列表支持批量选择

- 专辑 / 艺人 / 风格详情页此前没有「选择」入口（只有一级列表有）；
  现在详情页顶部同样提供「选择」，可多选并执行队列 / 歌单 / 隐藏 / 删文件 / 移除。

## 工程

- `DownloadPage` / `TaskItem` 增加 batchMode/selected 状态与勾选 UI（memo 比较器已同步）。
- 本地音乐工具行在二级详情中隐藏排序/筛选，仅保留「选择」，避免层级混乱。
