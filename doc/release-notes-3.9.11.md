# v3.9.11 发布说明

> 版本 **3.9.11** / versionCode **202**

## 设置页重构（第一批）
新增全新设置组件库 `Setting/components/ui`：
- `Group`：统一卡片分组（标题/说明/图标/分隔线）
- `ToggleRow`：新开关行（原生 Switch + 说明）
- `ChoiceRow`：胶囊选项行
- `ValueRow` / `ActionRow` / `StepperRow`：值、操作、数字步进行

已完成重写：
1. **播放与音质**：播放行为、音质/倍速/淡入淡出、启动与进度、缓存步进
2. **歌词与显示**：字号/对齐/偏移、逐字/单行/翻译/罗马音/粤拼/简繁、蓝牙与通知
3. **界面与动效**：主题模式、主题色、首页/动效/封面自转、语言/字体/音源名、导航玻璃/进度、分享
4. **下载与存储**：保存位置、文件名、音质、并发、换源、附加文件、边听边存、权限
