# v3.8.5 发布说明

> 版本 **3.8.5** / versionCode **187**（arm64-v8a 包 187003、armeabi-v7a 包 187001）
> Android 16（targetSdk 36），`minSdk 21`，ABI 仅 `arm64-v8a` + `armeabi-v7a`。

---

## 1. 排行榜 / 歌单广场标题右侧图标统一

- 5 个品牌来源图标放大（字形光学尺寸 ≈20dp，触控区 38dp），图标之间视觉间距统一 ≈10dp、与右侧圆形按钮组间距 8dp，全部与页头按钮同一水平线居中。
- 圆形按钮统一：排行榜播放/下载 38dp/icon20；歌单广场链接按钮（独立页与首页大卡入口）统一为 40dp/icon20 —— 首页大卡入口原来是 44dp/icon19 的自绘按钮，现已换成 PageHeader `HeaderButton`（带 M3 按压态）。
- 两处页头（排行榜、歌单广场）图标大小/间距规则完全一致；411dp 下余量充足；窄窗/横屏时标题先省略，图标与按钮不重叠、不换行；排行榜多选态隐藏来源图标逻辑保留。

## 2. 搜索页图标放大并铺满竖屏宽度

- 筛选行图标（歌曲 / 歌单 / 聚合大会 / 5 个品牌）从 18dp 放大到 **22dp**、触控区 38dp。
- 整行改为 `space-between` 铺满：9 个子项（8 图标 + 1 分隔线）固定宽约 305dp，411dp 屏内容区 395dp，8 个间隙均分 ≈11dp；容器左右 padding 8dp，使**首尾图标字形正好对齐 16dp 内容边距**（与搜索框、热门搜索胶囊左边缘对齐）。
- 窄屏/横屏放不下时自动退化为横向滚动，图标不被压扁；键盘弹出收起筛选行、点击切换、选中主色/未选中灰、无障碍标签全部保留。

## 3. 下载中心显示下载来源

- 任务状态行在「已完成 · 17.3 MB」后追加来源：**「已完成 · 17.3 MB · 酷我音乐」**。
- 映射：kw/kg/tx/wy/mg → 酷我音乐 / 酷狗音乐 / QQ音乐 / 网易云音乐 / 咪咕音乐；其它自定义音源显示脚本注册的显示名（取不到回退 source id）；无 source 的老任务不拼。
- 下载中 / 暂停 / 失败 / 等待 各状态同样追加来源；保持单行省略、不加图标/胶囊、颜色沿用状态行（完成绿、失败红）。
