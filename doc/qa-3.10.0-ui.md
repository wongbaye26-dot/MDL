### 真机发现并已修复的问题（本轮代码已更新）

1. **歌词设置 / 听歌统计全屏 Modal 标题被状态栏遮住**：两个 `Modal statusBarTranslucent` 容器未加安全区，补 `paddingTop: statusBarHeight`。
2. **长按只选 1 首时弹出的是单曲菜单**：`SelectInfo` 增加 `bulk` 标记，长按/多选栏进入一律按批量形态展示，不再出现「多选管理」重复项。
3. **定时关闭快捷卡文字被截断成「1…/3…/6…」**：两个原因叠加——5 个快捷卡挤压 + `ActionSheet` 快捷卡文字无宽度约束被 Android 压成 1 字符。改为 3 个快捷卡（15/30/60）+ 45/90 放操作行，并给 `ActionCard` 标签加 `width:'100%'` 居中。
4. 测试前设备系统动画缩放为 0，会导致所有动效「看起来没生效」；已在 QA 文档记录排查方法（`settings get global animator_duration_scale`），测试后恢复原值。
