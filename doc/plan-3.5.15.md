## 二、P0（本周内，不做会「静默坏」）

### 1. 原生补丁版本锁 + 构建校验
**问题**：`dependencies-patch.js` 靠文本锚点改 `react-native-track-player`，
升级依赖后锚点不匹配 → 按钮静默消失，构建不报错。

**做法**：
- `package.json` 里把 track-player 锁死（不带 `^`）
- `release.js` 前置检查：`grep` 补丁锚点，找不到就 `exit 1`
- 补丁文件里加版本号断言

**验收**：故意改错锚点 → 构建失败并提示「补丁锚点失配」。

### 2. 冒烟脚本修好并接入发版
**问题**：`scripts/smoke.js` 的导航比例按 5×58dp 算，实际是 4 图标 + 圆盘；`NAV_MARKER` 文案过期。实测 1/2 通过。

**做法**：
- 按实测重算导航槽位（4 图标 + 圆盘，244dp 宽 / 59dp 高）
- 更新 marker 文案
- `package.json` 加 `"smoke": "node scripts/smoke.js"`
- `release.js` 构建后自动跑一次

**验收**：`npm run smoke` 三条全绿（启动 / 切 Tab / 播放）。

### 3. 音源健康检查
**问题**：五音源（酷我/酷狗/企鹅/网易/咪咕）任一挂掉，用户只会看到「搜索无结果」。

**做法**：
- 启动时并发探活（每个音源搜一个固定词，2s 超时）
- 失败的音源在搜索页置灰并标注「暂不可用」
- 全部失败时提示「音源均不可用，请检查网络或自定义源」

**验收**：手动断一个音源域名 → 该音源显示不可用，其余正常。

## 三、P1（两周内，体验缺口）

### 4. 横屏共享元素转场
竖屏已有双向飞行，横屏是整页切换。把 `PlayerTransition` 按方向挂载，补横屏入口的起止矩形。

### 5. PageModal 退场动画
关闭时直接卸载。父级加 `closing` 状态，`SlideInView` 反向播放后再卸载。

### 6. 亮色玻璃退化处理
BlurView 在低端机不可用时，退化为「更深 tint + 1px 描边」，别让观感变薄。

### 7. 版本管理补课
- 打 `v3.5.15` tag
- 补 3.5.10~3.5.14 发布说明索引
- README「已知限制」同步到当前状态

## 七、一句话结论

原报告的「82 分」对**个人使用**是偏保守的——真正的短板不是「没测试」，
而是**「没有发版前能自动跑通的最小验证」**和**「依赖升级会静默坏」**这两件事。
把这两件补上，这个项目对个人使用就是稳的；测试和拆分属于「想长期维护时再做」。
