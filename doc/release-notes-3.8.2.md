# v3.8.2 发布说明

> 版本 **3.8.2** / versionCode **184**（arm64-v8a 包 184003、armeabi-v7a 包 184001）
> Android 16（targetSdk 36），`minSdk 21`，ABI 仅 `arm64-v8a` + `armeabi-v7a`。
> 本版按你反馈的 7 点逐项更新。

---

## 1. 歌词页英文排版 + 无歌词提示

- **英文/外文歌词版式**（按整页语言自动识别，无需设置）：
  - 左对齐（消除英文折行后「短尾巴居中错位」的视觉混乱）；
  - 均衡折行 `textBreakStrategy=balanced`，两行长度接近，不再出现一行只剩一两个词；
  - 行高改为 1.46×（折行行内部不再挤），行距统一由上下 padding 控制 → 单行/折行/高亮行之间间距恒定；
  - 长行仍完整显示、最多 3 行、不裁字；高亮行略大的效果保留。
  - **中文歌词版式完全不变**（居中 + 原行高），零回归。
- **无歌词提示**：两处入口统一为「圆形淡底图标 + 暂无歌词 + 当前歌曲没有可显示的歌词」，竖屏额外一行「轻触返回封面」且整块可点返回；去掉原来「暂无歌词 · 点击返回」的拼接文案。

## 2. 排行榜 / 歌单广场 / 本地音乐 / 搜索页 胶囊文字居中

- 共享 `Chip` 原语补上 `lineHeight = 字号+2`、关闭字体额外留白、垂直居中；`MiniTag`/`Tag` 同一套配方。
- 排行榜来源/榜单 chips、歌单广场来源/排序/分类 chips、本地音乐 5 个页签与歌曲行标签（时长/FLAC/采样率/码率）、搜索页热词/历史/类型 chips 全部水平+垂直居中；中英数混排都在正中。

## 3. 歌单详情：播放全部 / 收藏 / 下载 胶囊

- 三个胶囊作为一组在概览卡内**水平居中**（左右留白相等）；
- 每个胶囊内部「图标 + 文字」整体居中、左右 padding 对称（12/12）、高度统一 32；间距由 marginRight 改为 `gap: 8`（不再有尾随留白导致整组偏左）；多选态缩成圆形图标时同样居中，多选入口不受影响。

## 4. 来源品牌矢量 LOGO（替代「小蜗音乐…」文字）

- 新增 `SourceLogo` / `SourceChip`（react-native-svg），5 个品牌矢量图标：酷我（橙红·双音符）、酷狗（蓝·狗头）、QQ音乐（绿·音符）、网易云音乐（红·云+音符）、咪咕音乐（橙·M 波形）。
- 排行榜、歌单广场、搜索页的来源选择只显示对应品牌 logo，不再显示「小X音乐」文字；无障碍朗读仍是原音源名，点击/切换行为不变；未识别的自定义音源继续显示文字。

## 5. 去掉「胶囊描边」功能

- 设置 → 播放设置 →「底部胶囊进度条」现在只有 **封面圆环（默认）/ 关闭** 两项，胶囊描边选项与本轮之前的所有描边动效/进度光代码全部删除。
- 老用户如果之前选过「胶囊描边」，升级后设置 version 2.3 迁移自动改成「封面圆环」（幂等；选「关闭」的保留，翻译默认逻辑保留）。
- 胶囊任务栏、子页 PlayerBar、横屏迷你播放器、收藏页迷你条、横屏左侧导航统一为「圆环 / 关闭」两种表现，默认外观干净无动画光带。

## 6. 本地音乐删除确认改为 App 内 Material You 弹窗

- 删除文件确认从系统 `Alert` 换成 App 内圆角主题弹窗：危险红「删除」、淡底「取消」；取消/点遮罩/返回键都不会删除文件，只有点「删除」才真正删（语义与旧版一致）。
- 本地音乐目录内不再有系统 Alert 残留；「从列表移除」保持原行为（不弹确认）。

## 7. 设置界面列表化 + 顺序重排 + 设置项调整

- 设置首页从 8 卡宫格 → **列表样式**：一张 Material You 卡片内 8 行，每行 = 36dp 彩色圆角图标 + 标题 + 一行实时摘要 + 右侧 chevron；行间细分隔线。横屏左侧导航同步改为列表（图标 + 标题 + 选中高亮 + chevron），顺序一致。
- **新顺序**：播放设置 → 下载设置 → 音源管理 → 搜索与列表 → 音乐工具 → 基本设置 → 其他 → 关于（页面 id 不变，旧入口仍能定位）。
- 「搜索与列表」移除「添加歌曲到列表时的位置」设置项（保留已存值对已有行为的影响，仅去掉修改入口）。
- 「基本设置」里的「启动与播放」移入「播放设置」：启动后自动播放音乐、允许通过底栏进度条调整播放进度；基本设置只保留外观/主题色/界面/语言/字体/来源名称/分享。
