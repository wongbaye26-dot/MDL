# v3.5.17 发布说明（2026-11-03）

本轮只优化横屏播放队列（其它不动）：

- **横屏播放队列全屏**：v3.5.17 改为 Player 页内 absoluteFill 覆盖层（不再用 Modal/Dialog），打开时 Activity 级隐藏系统状态栏，关闭/切竖屏恢复；返回键关闭队列；退出后其它页面状态栏正常。
- **启动图标边缘渐变修复**：自适应图标前景改为透明画布 + 满幅 logo（不再 #0B0B12 黑底 + 80% 内缩），霓虹紫/粉渐变边直接到图标边缘。
- **通知栏/锁屏媒体按钮统一 Material 风格**：上一首/播放/暂停/下一首改用与收藏/循环同一套 24dp 白色 Material 矢量图标（native getIcon 支持资源名，dependencies-patch 幂等）。
- **首页卡片末端空白修复**：右侧留白从「一屏」改为 16dp，最后一张卡贴右边停住，不再出现像多余卡片位的黑色空白；吸附点用 snapToOffsets 前几张左对齐、最后一个吸附到内容末端。
- **封面播放/暂停按钮**：中间卡正中央增加胶囊任务栏同款磨砂玻璃圆形按钮（Glass + Material You 主色图标 + 半透明描边/高光/外阴影），点击只切播放/暂停、不触发卡片点击；侧卡仍是居中+直接播放。

## 升级注意

- 亮色玻璃依赖真实 BlurView（Android 模糊半径上限 25），若低端机模糊不可用会退化为半透明纯色，此时透明感会略弱。
- 设置右滑返回阈值 4dp 是为了抢在原生 PagerView 之前接管手势；极快甩动如果不触发，不会误切 Tab（有 PagerView 锁兜底）。
