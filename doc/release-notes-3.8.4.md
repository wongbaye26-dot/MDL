# v3.8.4 发布说明

> 版本 **3.8.4** / versionCode **186**（arm64-v8a 包 186003、armeabi-v7a 包 186001）
> Android 16（targetSdk 36），`minSdk 21`，ABI 仅 `arm64-v8a` + `armeabi-v7a`。

本版按你提供的 AppLogo 图标源（每家音乐 App 的官方图标）重做品牌 LOGO，并调整排行榜/歌单广场/搜索页的图标位置与样式。

---

## 1. 五个音乐 App 的真实品牌矢量 LOGO（单色）

- 酷我音乐 / 酷狗音乐 / QQ音乐 / 网易云音乐 / 咪咕音乐 的图标改为**按各自官方 App 图标自动描摹**的矢量路径，不再手绘近似：
  - 酷我：圆形笔触「K」+ 音符；
  - 酷狗：圆形「K」标志；
  - QQ音乐：官方音符 + 上扬符尾；
  - 网易云音乐：云涡 + 音符（官方曲线）；
  - 咪咕音乐：耳机 + 音符。
- 去掉了品牌底色/圆角方块：只有**单色字形**，48 视框、统一光学尺寸（16~20dp 下五个图标大小观感一致）、字形内部镂空用 evenodd 保留。
- Material You 单色：当前音源=主题主色，其它=次级灰；无胶囊、无背景、无描边，点击热区 34dp + hitSlop，按压透明度反馈；无障碍标签仍是原音源名。

## 2. 排行榜 / 歌单广场：LOGO 放到标题右侧

- 来源图标从原来的独立一排移到**页头标题右侧空白处**，与播放 / 下载 / 链接等圆形按钮同一水平线居中、对齐。
- 原来的独立来源行删除（榜单/排序/分类 chips 保留在原位）；排行榜进入多选时来源图标自动隐藏，给多选操作条让位，退出恢复。
- 窄屏/横屏：标题先省略、右侧图标组固定不压缩，不会重叠。

## 3. 搜索页：类型图标也换单色矢量

- 「歌曲 / 歌单」搜索类型：文字胶囊 → **单色矢量图标按钮**（歌曲=音符、歌单=列表+播放三角），与来源图标同规格（34dp 热区 + 18dp 图标、选中主色/未选中灰、按压反馈、无障碍文字保留）。
- 「聚合大会」音源选项：改为无胶囊的**层叠（聚合）单色图标**，与 5 个品牌图标同规格。
- 搜索页 5 个品牌来源图标同步为真实 LOGO 样式（同一组件）。
- 代码里搜索类型本身只有「歌曲 / 歌单」两种（`SearchType = 'music' | 'songlist'`），没有新增「聚合」搜索类型；「聚合」是音源选项（聚合大会/聚合搜索）。

## 说明 / 已知项

- 品牌 LOGO 版权归各公司所有，这里仅作「音源来源标识」使用；图形由官方图标描摹为单色矢量，不改变其商标含义。
- 排行榜页头在 411dp 宽度下较紧凑（标题只剩约 27dp 余量）；如需更松可把图标触控区 34→32dp（图标 18 不变）。
- 搜索页当前音源与排行榜/歌单广场各自独立（沿用原有逻辑），所以不同页面选中的来源可能不同，属原有行为。
