# EmoMusic v3.40.0 发行说明

> 版本 **3.40.0** / versionCode **330**

## 语种菜单改为仅图标样式
- 竖版歌词设置里的语种选择不再用 208 宽的文本列表；
- 改为与其它歌词设置一致的圆角图标列：
  - 自（自动判断）/ 粤 / 普 / EN / 日 / 韩；
- 当前语种高亮显示，点击立即生效；
- 竖屏为竖排图标，横屏为横排图标，不再出现错位。

## RN 升级 / 原生 HTTP 采集
- RN 0.73 → 0.76+ 需要整体升级（原生工程、依赖、ProGuard、Hermes），本轮未混入功能版本；
- 原生层（ExoPlayer/Fresco）HTTP 域名采集需要接各自网络栈，现有 JS 请求层只能覆盖接口请求，继续单独立项。
