# v3.6.8 发布说明

## 逐字歌词性能

- 上一版 v3.6.7 已把高亮从「按字符 slice」改为「按像素裁切」，本版继续解决整页重渲染问题：
  - 播放器页面的歌词时间轴只在**当前歌词行变化**时 setState，不再为了逐字高亮每 50ms 重渲染整个播放器；
  - 当前行的卡拉 OK 高亮由 `KaraokeText` 组件自己用 `requestAnimationFrame` 连续插值并裁切宽度；
  - 暂停/继续按真实进度重新对齐，切歌/拖动到其它行时重新从行进度起步。
- 视觉效果：高亮层在行内连续扫过，不再一格一格跳，也不会因为整页重渲染而卡顿。

版本 3.6.8 / versionCode 173。
