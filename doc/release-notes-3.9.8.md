# v3.9.8 发布说明

> 版本 **3.9.8** / versionCode **199**

## 表头液态玻璃无缝化
- 下载中心 / 本地音乐 / 收藏 / 排行榜 / 歌单广场 / 歌单详情 / 搜索页头：
  - 去掉底部 24dp 圆角；
  - LiquidGlass 进入 `seamless` 模式：去掉底部内阴影和 0.5dp 描边，只保留顶部高光；

- 我的（设置入口）页头、设置子页头同步接入同样的无缝玻璃。
