# v3.5.9 发布说明（2026-11-03）

本轮 7 项交互与视觉优化：

1. **关于页重做**：删除「项目仓库 / 问题反馈 / 开源协议」三条外链；品牌 hero 卡（LOGO / 名称 / 版本 chip / 标语 / 标签）+「技术信息」2×2 图标卡 + 致谢/声明统一圆角卡；修小屏下版本号被截断（chip 不收缩、footer 拆两行）。
2. **胶囊导航**：四个图标重绘（圆润线性 + 选中实心双色渐变，视觉 18~19dp）；选中圆底改为滑动 spring 过渡（不再硬切）、图标选中轻弹；磨砂更厚（tint/高光/内阴影加强，0.5dp 高光描边），胶囊外阴影加强。
3. **设置二级页手势**：去掉「下滑返回」；改为 **左滑返回**（整页跟手左移 + 淡出，过屏宽 25% 或快速甩动关闭，否则弹回）；手势捕获优先于 PagerView，滑动过程中不会误切到「本地音乐」；返回键/左上返回按钮照旧；设置滑杆等交互控件不受手势影响。
4. **自定义源 / 打开歌单卡片**：自定义源列表改为 Material You 圆角卡（名称/版本/状态 chip、当前启用高亮、启用/删除、更新提醒开关）；导入弹窗与「打开歌单」弹窗统一为圆角 24 主题卡片 + 主色按钮 + 主题输入框。
5. **通知栏 / 锁屏**：通知展开视图新增「收藏」（实心/线框跟随收藏状态）与「循环」（列表循环/随机/单曲循环/顺序四态图标）两个按钮；compact/锁屏加入上一曲（上一首/播放暂停/下一首）；通知 color 跟随主题主色（Material You），并随主题/播放模式/收藏状态刷新。通过 `dependencies-patch.js` 给 react-native-track-player 2.1.2 打原生补丁（幂等，npm install 后自动生效）。
6. **页面切换动画**：补齐播放器 ↔ 胶囊圆盘、播放器 ↔ 迷你播放器的 **双向**共享元素转场——关闭播放器（左上 chevron / 下滑手势 / 返回键）时封面从播放器封面经大圆收回本次进入的起点，封面落位后再切回**原 Tab**；跨 RNN 页面（歌单广场/歌单详情）打开时先量首页圆盘，关闭收回首页圆盘；Tab 切换加淡入+上浮+微缩放；PageModal 统一 320ms ease-out；歌单广场 push/pop 补 320ms decelerate。
7. **首页 4 卡重做**：更高级的三段渐变 + 柔光斑点/高光/内阴影；四张卡各有专属持续动效（排行榜跳动柱状、歌单旋转黑胶、收藏漂浮爱心、音源扩散波纹）；横向卡片区改为居中吸附轮播，滚动时卡片 scale/位移/旋转/透明度联动，切换自然回弹。

**v3.5.8 / v3.5.9 真机验证修复**：

- 关于页版本号：窄 chip 在部分机型/字号下仍会被压成「v3.…」，改为把版本号并进副标题行（`v3.5.9 · 深夜下载 · 情绪收藏`），并保留「技术信息」里的完整版本号，任何宽度都不会截断。

## 升级注意

- 原生通知按钮由 `dependencies-patch.js` 注入 react-native-track-player 源码；若重跑 `npm install`，请确认 postinstall 输出无「没找到锚点」，否则通知按钮不会出现（不影响编译）。
- Android 13+ 的通知媒体卡片会叠加系统动态取色，最终观感以系统为准；锁屏上一曲由 compact 能力决定。
- 横屏布局没有共享元素转场层，横屏关闭播放器仍为整页下滑切页。
