## 3. 未完成 / 已知缺口

### A. 功能与体验缺口

1. **横屏没有共享元素转场**：竖屏胶囊圆盘/迷你播放器 ↔ 播放器有完整双向飞行转场；横屏仍是整页切换（代码注释已标注）。受影响场景：横屏点播放器/队列入口的观感。
2. **PageModal 只有进场、没有退场动画**：排行榜/歌单广场/收藏/本地音乐/设置子页关闭时直接卸载（由各父级 state 驱动），与打开动画不对称。
3. **设置二级页手势的边界情况**：正常速度右滑可返回；极快甩动在个别时序下可能不触发（有 PagerView 锁 + 回到「我的」的兜底，不会误切 Tab）。
4. **横屏队列的磨砂播放键**：队列已改为页内覆盖层，Glass 能采样到窗口内容；但按钮底下的封面模糊仍是近似效果（BlurView 在 Android 的采样层限制），不是"完美透视封面"。
5. **亮色磨砂依赖设备模糊能力**：BlurView 在 Android 的 blurRadius 上限 25；低端机/部分 ROM 若模糊不可用会退化为半透明色，观感会变"薄"。
6. **通知栏收藏/循环依赖原生补丁**：补丁通过 `dependencies-patch.js` 在 `npm install` 时注入 `react-native-track-player 2.1.2`；若未来升级依赖导致锚点不匹配，按钮会消失（构建不报错，属静默降级）。
7. **iOS 未适配**：项目定位 Android，README 已声明（非缺陷，但属平台覆盖缺口）。

### B. 验证缺口（本次审计无法闭环）

1. 竖屏「打开歌单」弹窗、自定义源卡片：本轮改版后**没有真机截图验收**（当时设备被微信视频/悬浮窗占用）。
2. 横屏队列「点侧卡直接播放 + 队列不关闭」：代码已改，真机点击验证被系统/微信浮层打断，未取得完整前后对比截图。
3. 设置右滑返回的快甩边界：只验证了正常速度与偶发失败路径，缺少稳定的自动化复现脚本。

### C. 工程化缺口

1. **无单元/集成测试**：`package.json` 无 `test` 脚本；无 `__tests__`/Jest 配置。
2. **现有冒烟测试已过期**：`scripts/smoke.js` 的底部导航比例（按 5×58dp 槽位算）与当前 4 图标 + 圆盘布局不一致，实测 `1/2 通过`（本地音乐页切换失败）；`NAV_MARKER` 文案也需随 UI 更新。
3. **无 CI**：无 GitHub Actions/流水线；构建、lint、冒烟全部本地手工执行。
4. **无版本 tag**：仓库只有上游旧 tag（v1.9.x），本项目版本（3.5.x）没有打 tag，回溯构建基线只能靠 commit message。
5. **无崩溃/性能监控**：仅本地日志（`utils/log`），线上问题无法归因；238 处 `console.log/warn` 混在业务代码里。
6. **巨型文件**：`Player/index.tsx` 1,639 行、`LocalMusic/index.tsx` 1,452 行、`Favorites.tsx` 670 行；状态/动画/布局/业务集中在单文件，回归成本高。
7. **类型与规范宽松**：143 处 `any`、112 处 `eslint-disable`、31 处 TODO/FIXME/HACK（当前 tsc/eslint 本身是 0 error）。
8. **i18n 不完整**：120 个 TSX 文件中约 1,784 行含硬编码中文；主要面向中文用户，英文/繁体覆盖有限。
9. **无无障碍支持**：全仓 `accessibilityLabel` 为 0；TalkBack/大字体体验未覆盖。
10. **文档缺口**：`doc/` 缺 3.5.10~3.5.14 独立说明；README「已知限制」仍只列 iOS/音源/通知遮挡三条，与当前状态（横屏转场、PageModal 退场、测试缺口）不一致。

### D. 安全 / 合规缺口

1. 权限较重：`MANAGE_EXTERNAL_STORAGE`（所有文件访问）、`SYSTEM_ALERT_WINDOW`（桌面歌词）、`REQUEST_INSTALL_PACKAGES`（应用内更新）。自签名侧载合理，但应用商店审核会重点审查。
2. 无隐私政策/权限使用说明页；无数据分析、无崩溃上报（隐私友好，但也是可观测性缺口）。
3. 在线音源依赖第三方接口与用户自备自定义源，内容合规性由用户/上游承担（README 有声明）。
4. 签名与密钥管理规范：release 用独立 keystore，`keystore.properties`/`*.keystore` 已 gitignore（`debug.keystore` 除外），`keystore-info.js` 可核指纹，**未发现密钥泄漏**。
