# EmoMusic v3.26.1 修复说明

> 版本 **3.26.1** / versionCode **313**

## 年份/风格仍不全
- 根因：QQ 专辑接口只对 `tx` 匹配结果生效，而中文歌大多匹配到 `kw`（酷我），所以从未查询专辑元数据；
- 修复：任意源匹配后，用「专辑名 + 歌手」反查 QQ 专辑，再取 `aDate/genre/lan`；
- 结果按专辑缓存，避免重复请求。

## 语言
- 优先使用 QQ 专辑 `lan`（国语/粤语/英语…），比歌词判断更准。
