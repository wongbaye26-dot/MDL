# v3.8.0 发布说明

> 版本 **3.8.0** / versionCode **182**（arm64-v8a 包 182003、armeabi-v7a 包 182001）
> Android 16（targetSdk 36），`minSdk 21`，ABI 仅 `arm64-v8a` + `armeabi-v7a`。

本次针对你列的 10 点逐项更新：

---

## 1. 歌词页：英文显示 / 翻译 / 行距

- **英文/外文长行不再截断**：普通歌词行不再强制 `numberOfLines={1}`，主歌词允许折 2~3 行；逐字高亮层与底字使用完全同款字体，修掉行尾字母被裁；折行时高亮改为按进度给整段文本内嵌 span 染色，不裁字不跳行。
- **行距自适应**：去掉「有翻译/注音时每行固定 +40dp」的写法，行高按实际内容（主歌词行数 + 翻译/注音行数）计算，开启翻译后只有存在翻译的行变高，整体紧凑不空旷；滚动定位改用实测行布局，行高变化时自动重新居中。
- **歌词翻译**：歌词页工具行新增「翻译」开关（translate 图标，与设置项联动，**默认开启**、老用户升级一次性迁移）；外文歌词下方显示中文翻译（tlyric）；修复部分音源主歌词 `[mm:ss.SSS]` 与翻译 `[mm:ss.SS]` 时间精度不一致导致整段翻译挂不上的问题（按毫秒 ±250ms 对齐重建）；当前源没有中文翻译时静默从其它音源补一次（整行文本相似度 ≥35% 防串版本，失败不阻塞、不伪造）。
- **修复粤拼占位 bug**：开启粤拼时英文/泰文行不再输出「[…]」占位行；中英混排行里的占位符也剥离；翻译行与注音行做了视觉区分（翻译行稍大/更亮，注音行更淡）。

## 2. 排行榜

- 歌曲列表从卡片行改为与歌单详情一致的**列表行**（保留名次徽章、音质/来源角标、时长、⋮ 菜单、长按菜单、多选、下拉刷新、加载更多）。
- 标题右侧「播放全部 / 下载全部」按钮统一为本地音乐 / 下载中心页头同款：38dp 圆形、icon 20、主色淡底、间距 6。

## 3. 歌单详情封面

- 根因：kw/kg 等音源「歌单歌曲列表」接口不返回单曲专辑封面（映射层 `img: null`），只有歌单概览有封面。
- 修复：列表层对没有封面的歌曲异步补在线封面（并发 3、进程级缓存、失败不重试、300ms 分批刷新避免整表重渲染，不触发换源），补图前用歌单封面兜底；进页面先有封面，随后逐张替换为真实专辑封面。

## 4. 本地音乐

- 去掉「列表/卡片」切换与卡片样式，统一列表样式。
- 页头只保留「扫描文件夹 / 重新扫描」两个按钮，大小与样式对齐下载中心页头（38dp 圆、icon 20）。
- 新增**本地搜索**：歌名 / 歌手 / 专辑实时过滤（大曲库输入不卡顿）、清空按钮、无结果空态与「清空搜索」、搜索时跨页签平铺并给出「在全部歌曲中搜到 N 首」提示，与扫描/页签/播放都兼容。

## 5. 下载中心

- 任务列表改为非卡片列表行（与本地音乐列表一致），进度/暂停/重试/删除/多选/长按菜单保持。
- 音质标签改为「选择下载音质」弹窗同款短胶囊，并放在第二行独立显示，**320k / 128k / Hi-Res / FLAC 无损 都完整显示**（不再截成 320/128）。

## 6. 首页歌单广场卡片动效

- 根因：唱片是径向对称图形，自转（15s/圈）肉眼几乎看不出；不是动画没跑。
- 修复：歌单广场卡片新增「绕盘心公转高光 + 双层呼吸光晕」（native driver），保留唱片自转；首页四张卡都有持续可辨动效。

## 7. 迷你播放器 / 底部胶囊

- 横竖屏迷你播放器、子页 PlayerBar、收藏页迷你条的专辑封面统一为**胶囊任务栏同款 48dp 唱片圆盘**（54dp 进度环、描边/高光/阴影/自转/呼吸一致，共享元素起点统一 48）。
- 胶囊任务栏：去掉整条 0.5dp 实线描边，改为**局部渐变高光 + 跑马灯呼吸光带**（沿边缘缓慢移动 + 透明呼吸，纯 transform/opacity native driver，不逐帧重渲染）。
- 进度条默认改为**封面圆环**：progress=0 也显示完整圆环轨道，有进度时多层柔光弧自然叠在轨道上；默认设置改为 ring 并对老用户做一次性迁移。

## 8. 搜索页热门搜索

- 键盘弹出时热门搜索改为紧凑布局（更小胶囊/更紧间距）并让出顶部筛选行高度，一屏可见多行且可上下滚动到历史搜索；收起键盘自动恢复原布局。

## 9. 在线播放 / 下载提速

- **下载**：原生从单连接升级为「`Range: bytes=0-0` 探测 + 2~4 连接分段并发写同一 `.part` + 任一分片失败自动回落单连接」；单连接 buffer 64KB → 128KB；线程数按当前并发任务数自适应（总连接 ≤8）；断点续传保留（新增 `.part.seg` 分段进度），暂停/取消/进度/文件校验/MediaScanner 均保留。
- **播放**：ExoPlayer 缓冲改为 `minBuffer 15s / maxBuffer 45s / playBuffer 1.5s / backBuffer 30s`（起播所需缓冲从默认 2.5s 降到 1.5s，不再无脑预拉几十首）；下一首 URL 在切歌后 3s 预解析、最后 30s 兜底重试（最多 3 次、8s 退避），手动点「下一首」可直接命中 URL 缓存。

## 10. 音乐工具加强

- 曲库体检从 6 项扩到 **9 项**：新增重复歌曲分组、重复多余数、低码率（<192kbps）、时长异常/未知（<15s / >3h）。
- 新增 **一键修复**：按「补封面 → 刮削标签 → 补歌词」串行、每首只补缺的；有进度/停止/失败清单，结果可复制或导出 txt。
- 新增 **重复歌曲**：按歌名+歌手分组、预览，清理时只移除曲库记录、**不删文件**。
- 新增 **批量重命名**：模板 `{歌名}/{歌手}/{专辑}`（默认 `{歌手} - {歌名}`），先预览（可改名/冲突/SAF 跳过分类），执行时同步同名 `.lrc`、曲库记录与媒体库。
- 原有封面/标签/歌词/无效条目工具都增加逐项失败清单与「复制/导出报告」。

## 真机验收（SM-S938B / Android 17）

- PASS：歌词页、排行榜、歌单详情、本地音乐、首页动效、迷你播放器/胶囊、搜索键盘态、下载/播放速度、音乐工具、8 卡设置与主要页面回归；`FATAL EXCEPTION` = 0。
- 速度实测：320k/7.2MB 下载 ≈2s（≈3.6~3.8MB/s）；切歌 Preparing→onPlay 12ms、PLAYING ≈0.54s。
- 详细报告：`doc/qa-3.8.0.md`（141 件截图/日志证据在 `.tmp-verify/qa-3.8.0/`）。

## 已知问题 / 遗留

- 歌单详情首屏约 5~10s 内部分行封面为空（随后异步补齐）；暂无骨架占位。
- 本地音乐搜索：键盘弹出时结果区偏小/需收键盘查看（P3，后续优化）；空态「清空搜索」按钮偶发点击无反应（P3）。
- 批量重命名的「生成预览」偶发点击未响应（P3，可能与点击/滚动时序有关）。
- 在线音源自带 tlyric 的翻译链路、中文歌粤拼在本次验收窗口内未取到在线样本，建议后续专门补测。
- 横屏左侧导航的圆盘仍是旧的 56dp 分段点环，未与本轮新圆盘统一（用户未要求，后续可统一）。
- 16KB page size 设备限制（见 `doc/android-16-compat.md`）。
