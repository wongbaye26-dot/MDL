## 9. 现状问题（重构依据）

1. **两个超级页**：播放设置 7 组 21 项、音乐工具 13 张卡；滚动深、找不到东西。
2. **分类语义混合**：播放页里含歌词/通知/缓存；其他页含缓存/日志/权限/保活；基本设置「界面」含动效/字体/语言/音源名。
3. **命名不统一**：「悬浮栏玻璃效果」「底部胶囊进度条」是外观项，却在播放页；「权限管理」与「设备与权限」重复感强。
4. **缺少设置搜索**：21+ 项后没有搜索框，只能靠记忆翻页。
5. **缺少「恢复默认/重置」**：单页无重置入口，出错只能逐项改。
6. **入口卡片副标题是动态状态**（Hi-Res·逐字、历史开·热搜开），信息密度高但难扫读。
7. **音源管理没有分组容器**，与其他页的 Section 语言不一致。
8. **工具页缺少「常用/高级」分层**：普通用户只需要一键修复/回收站，数据库自检/歌词自检属于高级诊断。

## 10. 建议的新一级结构（草案，待确认）

| 新一级 | 收纳内容 |
|---|---|
| 播放与音质 | 播放行为、音质、倍速、淡入淡出、音频焦点/卸载、缓存上限 |
| 歌词与显示 | 歌词字号/对齐/偏移/逐字/单行、翻译/罗马音/粤拼/简繁、蓝牙歌词、通知封面 |
| 界面与动效 | 主题模式、主题色、Material You、字体、语言、首页滑动、卡片动效、封面自转、导航玻璃/进度样式 |
| 本地曲库 | 扫描目录、显示项、隐藏内容、回收站、曲库体检/一键修复/重命名/去重 |
| 音源与搜索 | 当前音源、音源列表、音质矩阵、音质检测、热搜/历史、列表点击/专辑名/时长 |
| 下载与存储 | 下载目录、文件名、音质、并发、换源、歌词/封面/元数据、边听边存、存储权限 |
| 系统与权限 | 通知权限、音乐权限、所有文件访问、电池优化、自启动、品牌保活 |
| 缓存、日志与关于 | 资源/歌曲信息缓存、日志、检查更新、致谢、声明 |

### 重构时建议一并补的能力
- 设置页顶部**搜索框**（按标题/关键词过滤）；
- 每个一级页支持**恢复默认**；
- 危险操作（清空缓存/回收站/数据库自检）统一红色警示与二次确认；
- 入口卡片副标题改成「固定说明」，动态状态放到页内；
- 统一 Section / Card / Row 三种容器，音源管理也套 Section；
- 工具页拆「常用工具」与「高级诊断」两组，默认收起高级。
