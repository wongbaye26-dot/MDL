# EmoMusic v3.22.0 发行说明

> 版本 **3.22.0** / versionCode **297**

## 音乐工具：语言/年份/风格联网刮削
- 新增「语言 / 年份 / 风格可补全」区域与「补全语言/年份/风格」按钮；
- 每首：
  - 联网匹配歌曲（歌名+歌手核对）；
  - 从搜索结果取发行年份/风格；
  - 拉取匹配源歌词，按日文假名/韩文/粤语用字/中英比例判断语言；
  - 写入 FLAC 的 DATE/GENRE/LANGUAGE 标签，并回写曲库；
  - 写文件失败也会回写曲库。
- 曲库体检新增 `metaIncomplete` 列表（缺任一项即列出）。

## 配套
- 本地歌曲信息页可手动编辑语言/年份/风格；
- 本地「风格」tab；
- 播放器按语言自动开粤拼/翻译。
