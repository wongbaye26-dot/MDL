# EmoMusic v3.12.17 修复说明

> 版本 **3.12.17** / versionCode **280**

## 收藏页崩溃 / 歌单不能播放
- 之前加入歌单的精简条目缺 `meta`/`source`，导致收藏页排序、播放、缩略图异常；
- 启动时自动修复用户歌单：
  - 能按 id 从本地曲库找回完整条目就替换；
  - 找不到的无效条目移除；
- 排序/行渲染/文件菜单全部加空值保护。

## 歌单瀑布流
- 双列瀑布流，卡片高度按 210/158/190/146/202/170 交错；
- 封面用歌单内第一首音乐，异步提取本地封面（占位图标打底）；
- 保留删除按钮、歌单名/数量渐变遮罩。

## 添加歌单
- 本地/在线音乐均通过现有 `ListMusicAdd` 加入。
