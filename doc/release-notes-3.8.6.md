# v3.8.6 发布说明

> 版本 **3.8.6** / versionCode **188**（arm64-v8a 包 188003、armeabi-v7a 包 188001）
> Android 16（targetSdk 36），`minSdk 21`，ABI 仅 `arm64-v8a` + `armeabi-v7a`。

---

## 1. 五个音乐 App 的 LOGO 更换（你提供的官方 SVG → 单色矢量）

- 采用你提供的酷我音乐 / 酷狗音乐 / QQ音乐 / 网易云音乐 / 咪咕音乐官方 SVG，提取**标志字形**重做成单色矢量图标：
  - 酷我：圆形笔触「K」+ 音符；酷狗：圆环「K」；QQ音乐：官方音符；网易云：云涡音符；咪咕：耳机 + music。
- 全部**单色 Material You**：当前音源=主题主色、其它=次级灰；无品牌彩色底/无描边/无胶囊；48 视框、统一光学尺寸（5 个图标在 18~27dp 下大小一致），字形内部镂空保留。
- 排行榜 / 歌单广场 / 搜索页三处来源图标同步换成这套新 LOGO。

## 2. 歌单广场 / 歌单详情去掉返回按钮，标题与排行榜对齐

- 两处页头不再显示左侧「←」返回按钮；标题左边缘、字号（21sp/横屏 19sp）、垂直位置与「排行榜」标题完全一致（都用同一个 PageHeader 样式，标题单行省略）。
- 返回方式保持原样：系统返回键 / 侧滑手势逐层返回（歌单详情 → 歌单广场 → 首页），没有新增按钮、没有改动任何返回/手势逻辑。
- 首页「歌单广场」大卡实际打开的是独立歌单广场页（同一处修改已覆盖）；说明：代码里 Home 的 songlist PageModal 分支是不可达的旧代码，本次未清理（不影响）。
