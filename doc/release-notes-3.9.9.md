# v3.9.9 发布说明

> 版本 **3.9.9** / versionCode **200**

## 表头液态玻璃扩展
- 排行榜、歌单广场：页头下方的排序/分类胶囊行加入同款无缝 LiquidGlass；
- 歌单详情：顶部歌单介绍卡改为 LiquidGlass（保留主色描边）；
- 本地音乐：页签栏 + 排序/筛选/选择工具栏加入 LiquidGlass，与页头连成一片。

## 收藏页重构
- 页头 4 个标签：**歌单 / 收藏 / 试听 / 新建歌单**；
- 「歌单」标签为自建歌单网格：概览卡 + 新建按钮 + 两列歌单卡（名称/曲数），点卡片进入该歌单歌曲列表；
- 「新建歌单」直接打开新建列表弹窗。

## 最近添加专辑
- 首页「最近添加专辑」点封面 → 直接打开本地音乐对应专辑的歌曲列表（不再只落到专辑总览）。

## 设置页按 8 类重构
首页分组与子页全部按新结构：
1. 播放与音质（播放/启动与进度/缓存）
2. 歌词与显示（歌词/通知）
3. 界面与动效（外观/主题色/界面/导航与动效/分享）
4. 本地曲库（列表显示 + 全部音乐工具）
5. 音源与搜索（音源管理 + 搜索）
6. 下载与存储（原下载设置全部内容）
7. 系统与权限（权限管理 + 设备与权限）
8. 缓存、日志与关于（缓存/其他规则/日志/关于）

旧设置页 id 自动迁移；横屏左侧导航同步 8 类。
