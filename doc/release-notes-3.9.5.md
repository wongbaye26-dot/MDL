# v3.9.5 发布说明

> 版本 **3.9.5** / versionCode **196**（arm64-v8a 包 196003、armeabi-v7a 包 196001）

## 首页搜索
- 搜索按钮从页头移出，改为**固定悬浮在右上角**；
- 外框使用胶囊任务栏同款 **液态玻璃**（静态高光/内阴影，无扫光）。

## 迷你播放器歌词
- 横屏迷你播放器、子页 PlayerBar、收藏页迷你播放器的第二行优先显示当前歌词；无歌词时回退歌手。

## 本地音乐
- 标题后新增 **收藏按键**，打开「我的收藏」；
- 歌曲列表封面 `inset=0`，去掉主题色外框；
- 右侧字母栏改为**定位/高亮**：滚动时当前首字母高亮（缩放 + 透明度 spring），点字母滚动到对应位置；不再筛选；
- 移除列表右侧滚动条。

## 验证
- typecheck 0 / lint 0 / test 19/19；assembleRelease 成功；
- 真机：悬浮搜索、收藏键、封面无框、字母栏 G 段高亮/点击跳转、无滚动条。
- 迷你播放器歌词视觉 NOT RUN（需横屏/子页播放时确认）。

## 已知
- 字母栏点击跳转失败时按平均行高回退，极端大曲库可能需再点一次；后续可加精确 getItemLayout。
