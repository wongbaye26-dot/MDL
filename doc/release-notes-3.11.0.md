## 本版重点

### 本地曲库 / 迁移
- tracks.id 迁移真机应用、回滚、重应用通过；
- 曲库/DB 全部 fp 主键（244/0），列表本地引用已迁移；
- 冷启动首屏：JSON 快照 + 8 行骨架，不再白屏等 SQLite。

### 本地音乐页
- tab 切换根因修复：排序函数纯化 + 5 组 rows 预计算缓存，切换接近即时；
- 设置页显示问题修复：胶囊/值文字不再吞末字；
- 迁移自检入口对普通用户隐藏。

### 设置
- 8 分类全部使用新组件；
- 显示裁切修复（文件名格式、下载音质、资源缓存、版本/框架/设计语言/平台）；
- 旧设置死代码清理（移除无引用目录）。

### 收藏页
- 标题右侧 4 个圆形图标（歌单/收藏/试听/新建）；
- 歌单改横排卡片，支持按钮/长按删除；
- 删除确认、空状态。

### 桌面小组件
- 2×2：封面铺满、底部渐变虚化、歌名/歌手居中、三键等宽居中、无进度条；
- 4×1：圆形封面、液态玻璃、歌词行、进度条、三键；
- 明暗主题同步、无封面兜底、进度 2s 同步、重启恢复。

- 按原型重做：周期页签、大时长、唱片插画、7 日柱状、三指标、本周最爱。
