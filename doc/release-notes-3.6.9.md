# v3.6.9 发布说明

## 粤语歌词注音

- 歌词页支持显示 LRC 的扩展行（`extendedLyrics`：翻译 / 罗马音 / 粤拼注音）：
  - 打开 **设置 → 播放设置 → 显示歌词注音/罗马音** 后，若音源返回了 `romalrc`（例如网易云粤语歌会返回粤拼），会以小字显示在对应歌词行下方；
  - 歌词行高自动增加，滚动定位按新行高计算，注音行跟随当前行高亮。
- 说明：这里用的是音源自带的整行注音数据（NetEase 的粤语 `romalrc` 是整行粤拼，不是逐字 ruby）。如果音源没有注音、需要按字自动生成粤拼，需要内置粤拼字典并处理多音字，属于后续增强。
