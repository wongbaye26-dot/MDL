# EmoMusic v3.12.24 发行说明

> 版本 **3.12.24** / versionCode **287**

## 歌单详情
- 移除概览卡返回图标；
- 支持系统返回键 / 右滑返回歌单封面页；
- 歌单歌曲列表恢复专辑封面、本地/在线标签、时长（进入歌单时再次修复损坏条目）。
