# v3.5.6 发布说明（2026-11-03）

本轮 6 个细节优化（继续对齐飞牛音乐 / 统一新版 UI 语言）：

1. **播放器竖屏间距**：进度条下方「时间 + 歌曲信息」行按飞牛音乐收紧（间隙约 15dp → 8dp）；进度条与控制区位置不变，封面态/歌词态切换不跳。
2. **横屏播放列表复刻飞牛**：3D 封面流按飞牛实测重调——中间卡约 60% 屏高、相邻卡 0.72 倍间距、旋转 20/26/32° 递进且方向修正为「外缘朝镜头」、去掉暗幕/播放键遮罩/描边，背景当前封面重模糊 + 通透暗幕，中间卡下方居中歌名/歌手；保留滑动吸附/点卡切歌。
3. **热门搜索**：10 条从「5 列 × 2 行」改成「2 列 × 5 行」宽胶囊，关键词完整显示不再截断。
4. **收藏页**：
   - 「我的收藏 / 试听列表」胶囊移到页头「收藏」标题右侧同一行；
   - 歌曲行的本地标签由「LOCAL」改为「本地」；
   - 试听列表只展示最近 30 首（展示层截取，不改真实播放队列；点击/菜单/多选按真实索引映射），避免长列表末尾空白。
5. **排行/歌单详情的更多菜单**：从底部 Sheet 改为 **Material You 悬浮菜单**——点行尾 ⋮ 或长按，在触发点附近弹出小卡片（贴边自动翻转/夹屏、圆角 16、主题配色、缩放淡入），不再遮住整屏；菜单新增「多选管理」入口，保留原全部 action。本地音乐/下载中心仍用底部 Sheet。
6. **排行榜 / 歌单广场 / 歌单详情版面统一优化**：
   - 排行榜：页头改紧凑播放/下载圆钮；音源/榜单两排筛选胶囊收紧并统一选中态；歌曲列表改 **卡片行**（保留名次、音质/来源角标），长按悬浮菜单浮在卡片上；
   - 歌单广场：三列改 **两列大卡片**（封面 1:1 圆角 16、标题 2 行、播放量角标），三排筛选合并为两排；修 VirtualizedList 只渲染首批导致下方空白的问题；
   - 歌单详情：补固定页头（返回 + 歌单名）；概览区改成和本地/下载一致的圆角概览卡（封面 + 标题/作者/简介 + 播放全部/收藏/下载）；空态统一，底部 PlayerBar 保留；
   - 三页共用统一空态样式。
