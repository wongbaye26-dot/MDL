# 本地音乐管理与播放 2.0 · 开发需求（v3.9.1 / 阶段 A-1+）

- 提出日期：2026-11-06
- 依据：现有代码（`src/core/localMusic`、`LocalMusic/index.tsx`、`plugins/player`、`Setting/settings/Tools`）+ `doc/progress-3.9-4.0.md`（A-1 曲库体验、A-2 存储迁移、T 音乐工具）
- 结论：**不换存储、不改现有播放内核**，用 4～5 周 / 约 26 人日做一版“找歌快、曲库干净、播放顺手”的本地音乐 2.0；A-2 的指纹主键和 T 的深度编辑器仍按原计划后置。

---

## 1. 为什么现在做

现有本地音乐已经能扫、能放、能补标签，但用户能明显感受到的短板集中在「找、管、放」三件事：

| 现状（代码证据） | 用户感知 |
|---|---|
| 本地曲目 `id = local_${filePath}`，meta 只有 `filePath/ext/mtime/contentUri/size/bitrate/sampleRate`（`core/localMusic/index.ts:194`） | 换目录、改文件名、换设备后歌单/收藏里的本地歌全部失效 |
| 扫描是**全量两段式**：遍历目录 → 逐首补标签；`MAX_DEPTH=4`，失败静默（`scrape.ts`、`readMetadata`） | 几千首每次重扫都很慢；某些目录扫不到没有任何提示 |
| 浏览只有 全部/文件夹/专辑/艺人/最近添加 五个页签；没有排序、筛选、流派、专辑/艺人聚合封面（`LocalMusic/index.tsx:62`） | 专辑墙、艺人墙是“封面拼贴缺失”的；大库只能按页签硬翻 |
| 搜索只按 歌名/歌手/专辑 字符串包含；A-Z 首字母栏只做筛选（`pinyinInitial.ts`） | 记不住完整歌名就搜不到；文件名里的信息用不上 |
| 播放侧：`setPlaybackRate` 已封装但**无 UI**；无淡入淡出、无队列持久化/重启恢复；`audioOffload` 有设置项 | 倍速要进系统/第三方；重启 App 队列和进度要重来 |
| 工具侧已有 曲库体检/批量补封面/刮削标签/补歌词/重命名（`Setting/settings/Tools`），但**没有重复歌曲、缺失文件、失权目录、隐藏、不可解码标记** | 同一首歌多份、文件丢了、目录授权失效，只能自己翻 |
| 队列/最近播放只在内存或 20 条 recentPlay；无 M3U/CUE | 导入导出歌单、整轨 CUE 分轨都做不到 |

> 关键判断：**先做“索引 + 增量扫描 + 列表体验 + 播放顺滑”**，收益最大且不动存储；指纹迁移、CUE 无缝、ReplayGain 等重活放到 A-2/T，避免一次性大改。

## 2. 目标与非目标

### 2.1 目标（可量化）

| 指标 | 现状 | 目标 |
|---|---|---|
| 10,000 首冷启动曲库可用 | 每次读 JSON + 全量派生 | ≤ 800ms 显示首屏（索引缓存命中） |
| 增量扫描 1,000 首（无变化目录） | 全量遍历 + 读标签 | ≤ 8s，且不重复读未变化文件的标签 |
| 列表首屏/滚动 | 全量数组排序 + 大量挂载 | 首屏 ≤ 400ms；滚动 ≥ 55fps（中端机） |
| 搜索 P95（歌名/歌手/专辑/文件名/拼音首字母） | 仅字符串包含 | ≤ 200ms（10k 曲库） |
| 失权目录/缺失文件 | 静默或只在扫描卡提示 | 100% 可见、可定位、可一键重授权/清理 |
| 重复歌曲识别 | 无 | 精确率 ≥ 98%，可试听对比后合并 |
| 播放队列重启恢复 | 无 | 100% 恢复（含队列、当前曲、进度） |
| 倍速 | 无入口 | 0.5×～2.0×，步进 0.1，重启保留 |
| 切歌淡入淡出 | 无 | 0～12s 可配，真机无爆音 |

### 2.2 非目标（本需求不做）

- 不做存储迁移、不把主键换成音频指纹（A2-04 再做；本需求只预留 `fingerprint?` 字段）。
- 不做批量写标签/自定义标签/TTML 歌词编辑（T-02～T-04）。
- 不做真·交叉淡入（两首重叠播放）——RN Track Player 不支持，P2 再评估原生扩展；本需求只做“淡出→切→淡入”。
- 不做 DSD/APE/WMA 解码扩展（B-03 FFmpeg 之后）。

## 3. 需求范围（P0 / P1 / P2）

### P0 · 必须（本版发布的核心理由）

#### L-01 派生索引层（复用 A1-01）
- 从 `MusicInfoLocal[]` 一次构建并缓存：`albums`、`artists`、`folders`、`genres(可空)`、`albumArtist`、`recentAdded`。
- 索引项：`key(name 归一化)`、`displayName`、`songCount`、`totalSeconds`、`coverUrl`（取第一首有效封面/刮削结果）、`songIds`。
- 持久化：`local_music_index_v1`（JSON，带曲库版本号 + 构建耗时/曲目数）；曲库变化后 debounce 重建。
- 内存/耗时日志：构建 ≤ 300ms（10k 首），内存增量 ≤ 8MB。

#### L-02 浏览升级
- 本地音乐主页保持五个内容页签，新增 **“专辑/艺人”聚合视图**：网格卡片（封面 + 名称 + 数量），复用现有 A1-09 规划。
- **排序**：歌名、歌手、专辑、时长、添加时间、文件路径；升/降序；每个页签独立记住上次排序（存设置）。
- **筛选**：格式（FLAC/MP3/…）、是否有封面、是否失效/失权、采样率/码率档位（有数据时）。
- **搜索**：在现有 歌名/歌手/专辑 基础上加 **文件名、路径、拼音首字母（已有 A-Z 栏复用）**；搜索框继续顶部悬浮，结果高亮匹配片段。
- 列表行信息保持三行：歌名 / 歌手·专辑 / 时长·格式·码率；点击行播放、长按进多选、行尾菜单不变。

#### L-03 扫描可靠性 2.0
- **增量扫描**：为每个根目录持久化 `{path, mtime, size}` 快照；扫描时只对新增/变化文件读标签，未变化直接复用旧条目；删除的文件从曲库移除并在“扫描报告”里列出。
- **可取消 + 进度**：扫描面板显示 当前目录/已扫描数/新增/更新/删除/失败；支持取消；取消后保留已完成部分。
- **失权与失败显式化**：`needAuth` 目录、读取失败文件进入“扫描报告”，主页顶部 banner 可点进修复；不再静默丢歌。
- **扫描触发**：下拉刷新（已有）、启动后增量扫描（已有冷启动扫描改为增量）、扫描文件夹面板内“重新扫描”（全量，带二次确认）。

#### L-04 曲库健康 2.0（接入现有体检）
- 新增体检项并给出数量 + 入口：
  - **重复歌曲**：归一化 `歌名+歌手+时长(±2s)` 分组；列表内并排展示路径/码率/大小，支持“保留最高码率/保留最早添加/手动勾选”，合并 = 收藏/歌单引用改到保留项（先做同列表引用，不做文件删除）。
  - **缺失文件**：曲库里 `filePath` 不存在（懒检查：进入体检时批量 stat，分批 yield）；支持从曲库移除。
  - **失权目录**：SAF 授权失效；支持重新选择目录并重扫。
  - **隐藏歌曲/文件夹**：`hiddenLocalIds`、`hiddenFolders` 设置；主页默认不显示，可在体检/设置里恢复。
  - **不可解码格式**：基于扩展名 + 已知解码白名单标记（APE/WMA/DSF/DFF 提示“可能不支持”）；播放失败时弹“用系统播放器打开/分享”。
- 体检结果可复制/导出（现有 `Card` 已支持复制，沿用）。

#### L-05 播放体验
- **倍速 UI**：播放器工具行/更多菜单加“倍速”，0.5×/0.75×/1.0×/1.25×/1.5×/2.0×；调用现有 `setPlaybackRate`；持久化 `player.playRate`；切歌保持。
- **淡入淡出**：设置项 `player.fadeSeconds`（0/2/4/6/8/12s）；切歌/暂停恢复时用 `TrackPlayer.setVolume` 做线性/余弦淡出→切→淡入；不改变音量设置值，结束后恢复原音量。
- **队列持久化**：每 5s / 切歌 / 退后台保存 `{listId, ids, index, position, updatedAt}`；冷启动恢复队列但**默认暂停**，播放器/迷你条显示“上次播放”，点击继续；文件不存在项自动跳过并在 toast 说明。
- **播放位置恢复**：`isSavePlayTime` 已有；确保本地曲目按 `id` 恢复，并在队列恢复时优先使用保存位置。
- **回归**：音频焦点、通知/锁屏、蓝牙、audioOffload、定时关闭、睡眠定时不被破坏。

### P1 · 应该（本版可跟车）

#### L-06 歌单导入导出（M3U/M3U8）
- 导出当前队列/收藏/任意歌单为 M3U8（UTF-8，`#EXTINF:时长,歌手 - 歌名` + 绝对路径/contentUri）。
- 导入 M3U/M3U8：匹配策略 `路径精确 → 文件名+大小 → 歌名+歌手+时长`；未匹配项列出，可手动指定；导入为普通歌单（非本地曲库写入）。
- SAF 选择文件，不申请全盘权限。

#### L-07 本地歌词管理
- 扫描时顺带识别同名 `.lrc`（已有 lyricFix 写歌词，反向读未做）；内嵌歌词读取失败时回退同名文件。
- 播放器歌词菜单加“歌词偏移 ±0.1s/±0.5s”（写 `player.lyricOffset` 每曲可覆盖全局）。
- 批量匹配本地歌词：选中多首 → 按同名/同目录/网络搜索顺序匹配，结果预览 + 写入（复用现有补歌词任务）。
- 注：简繁转换/逐字/TTML 归 T-04，不在本需求。

#### L-08 批量管理
- 本地音乐多选（已有长按多选基础）增加批量动作：加入播放队列、添加到歌单、隐藏、移除曲库（不删文件）、删除文件（二次确认 + 回收站策略：先移到应用回收目录 7 天）。
- 批量操作显示进度与结果（成功/失败/跳过），复用现有任务锁；任务历史归 T-01，本需求先给轻量 toast + 结果弹层。

#### L-09 播放信息与格式能力
- 播放器“歌曲信息”增加：文件路径（可复制）、格式/采样率/码率/声道（有则显示）、文件大小、添加时间。
- 不可解码/播放失败时，提供“用其他应用打开/分享文件”。

### P2 · 可以（下一版）

- 真·交叉淡入淡出（原生扩展双播放器）。
- 音频指纹去重（替代 `歌名+歌手+时长` 近似）。
- CUE 整轨分轨（依赖 A2-06/07）。
- ReplayGain 扫描与播放增益（T+-02）。
- 流派/年份/碟号/音轨号完整标签索引（需要扩展原生元数据读取字段）。
- 跨设备歌单/队列备份（云端同步）。

## 5. 技术与数据方案

### 5.1 不改存储的索引
- 新增 `src/core/localMusic/index.ts` 派生：
  ```ts
  interface LocalLibraryIndex {
    version: 1
    builtAt: number
    trackCount: number
    albums: Record<string, AlbumIndexItem>
    artists: Record<string, ArtistIndexItem>
    folders: Record<string, FolderIndexItem>
    genres: Record<string, GenreIndexItem> // 元数据可用时
  }
  ```
- 构建：一次遍历，`Map` 聚合，归一化 key（大小写/空格/括号）；封面优先 `picUrl`，其次同专辑第一首有效封面。
- 持久化：`saveData('local_music_index_v1', index)`，曲库变更 debounce 2s 重建；冷启动先读缓存再后台重建。
- **性能**：构建与扫描分片（每 200 首 `await new Promise(r => setTimeout(r, 0))`），避免 ANR（参考收藏页 ANR 修复）。

### 5.2 增量扫描
- 扫描快照：**直接复用已持久化的曲库 JSON**（每条自带 `filePath + mtime + size`），不额外维护第二份快照；曲库被清空时才退化为全量读标签。
- 三路扫描统一（MediaStore / SAF / 直接目录）输出 `{path, mtime, size, uri}`；与快照 diff：
  - 新增/变化 → 读标签
  - 未变化 → 复用旧 `MusicInfoLocal`
  - 文件不存在 → 移除并记录
- 失败/失权记录进 `scan_report_v1`，主页 banner 读取。

### 5.3 重复与缺失
- 重复 key：`normalize(name)|normalize(singer)|round(durationSec/2)`；单组内按 `bitrate → sampleRate → size` 排序推荐保留。
- 缺失检查：进入体检时对 `contentUri/filePath` 分批 stat（每批 200，`InteractionManager` 之后执行）。
- 隐藏：`local_hidden_ids` / `local_hidden_folders`，在列表派生层过滤，不删数据。

### 5.4 播放
- 倍速：`setPlaybackRate(rate)`（已有封装）；播放器初始化读取并应用；`TrackPlayer.setRate` 在切歌后重新应用。
- 淡入淡出：复用 `core/player/sleepTimer.ts` 已验证的 `setVolume` 渐降实现（1.2s 淡出→pause），扩展为“淡出→切歌→淡入”；可配置 0/2/4/6/8/12s；暂停/恢复可选（同一设置）。
- 队列持久化：`player_queue_state_v1`；启动时校验 `local_` 前缀条目的文件存在性；恢复后 `paused: true`。
- 播放失败：捕获 TrackPlayer error → 标“不可解码” → 弹“用其他应用打开”。

### 5.5 兼容与回滚
- 所有新增存储键带 `_v1`；设置项新增默认值，旧版本读到未知键会忽略。
- 索引/快照可安全删除（`clearLocalMusicCache` 扩展清理），删除后下次启动自动重建。
- 不修改现有 `MusicInfoLocal.id` 格式，队列/收藏/歌单引用不受影响。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 全量派生索引构建阻塞 JS | 启动卡顿/ANR | 分片构建 + InteractionManager + 缓存优先渲染；参考收藏页 ANR 修复 |
| SAF/MediaStore 行为差异 | 扫不到/重复 | 三路统一输出 + P0-04 样本矩阵；失权显式化 |
| 重复判定误合并 | 用户丢歌 | 只合并引用不删文件；合并前并排试听；可撤销（保留原条目 30 天） |
| 队列恢复引用失效 | 恢复后播放失败 | 恢复时逐个存在性校验，失败跳过并提示 |
| 淡入淡出与音频焦点/通知冲突 | 爆音/音量不恢复 | 只改播放器音量不写系统音量；结束强制恢复；真机矩阵覆盖 |
| 与 A-2 指纹迁移冲突 | 二次返工 | 本需求不动 id 格式；索引/队列/隐藏键都按 `local_` 前缀兼容，A-2 迁移时统一改 |
