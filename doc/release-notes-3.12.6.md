# EmoMusic v3.12.6 发行说明

> 版本 **3.12.6** / versionCode **269**

## 横版本地音乐
- 5 个 tab（全部/文件夹/专辑/艺人/最近添加）改为标题右侧圆形图标，与收藏/文件夹/搜索按钮同尺寸样式；
- 排序、筛选、选择改为标题右侧图标按钮；
- 横屏不再显示下方整排 tab 和筛选工具行，内容区更干净；
- 横屏专辑/艺人改用列表布局（不再用 3 列大图网格），解决图片过大的问题。
