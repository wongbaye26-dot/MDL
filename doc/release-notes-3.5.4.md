# v3.5.4 发布说明（2026-11-03）

本轮 8 个 UI/交互问题：

1. **更换新 LOGO**：用户提供的新「霓虹波形」图标已替换为应用图标 + App 内 logo（我的页 / 下载中心 / 关于页页头）。
2. **本地音乐更多菜单**：删除「查看所在目录」；菜单配色改为 **Material You**（跟随主题明暗与主色）。
3. **全站更多菜单统一**：下载中心 / 排行榜 / 歌单详情 / 搜索 / 我的列表的「更多菜单」全部换成同一套 Material You 底部 ActionSheet（布局沿用本地音乐更多菜单）。
4. **竖屏迷你播放器 → 播放器转场**：点歌单详情/歌单/排行榜/收藏页底部的迷你播放条，使用和底部胶囊圆盘一致的共享元素动画（小圆盘 → 中间大圆 → 播放器封面）；歌单详情等独立页面会先 pop 回首页再播放动画。
5. **播放器页**：
   - 「歌曲详情」图标由 ⋮ 换成 ⓘ；
   - 「歌曲详情」弹层改为 Material You 底部 Sheet（封面 + 歌名/歌手 + 只读信息行）；
   - 下载按钮只在**在线音乐**时显示，本地音乐隐藏；
   - 竖屏进度条下方的时间 + 歌曲信息整体下移 10dp（进度条与控制区位置不变）。
6. **收藏页面重做**：顶部概览卡（列表名/数量/播放全部）+ 胶囊页签 + 卡片列表，底部加**玻璃迷你播放器**（封面 / 歌名歌手 / 播放暂停 / 播放队列），点击封面进入播放器（带共享元素转场）。
7. **首页**：删除「本地音乐」卡片（入口保留在「最近添加」标题点击）；修复「最近播放」右侧统计（本地 N · 在线 N）被截断。
8. **搜索页**：
   - 热门搜索 10 条改为 5 列 × 2 行胶囊；
   - 修复搜索结果本地/在线逻辑：首次搜索、下拉刷新、加载更多都稳定展示本地匹配与「本地/音源」标记，不再出现「首次没有 / 刷新后本地消失 / 再搜才出现」；加载更多不再重复拼本地 10 首。

## 升级注意

- 覆盖安装请用 arm64 包；universal 包 versionCode 是裸号，只能全新安装。
- 启动图标是 APK 资源，替换后部分桌面会缓存旧图标：如仍显示旧图标，可**卸载重装**或换用其它启动器/清理启动器缓存。
- 新 LOGO 原图在 `design/logo/emo-logo-new-src.png`，生成脚本 `design/logo/generate-icons.py`（可复现重出各尺寸）。
