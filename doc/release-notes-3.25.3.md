## 新增「曲库字段诊断」

- 歌曲信息页底部新增「曲库字段诊断」，直接显示该歌内存里的 `id/name/singer/interval/meta` JSON。

用于确认：文件有标签但曲库没有，还是曲库有但界面没显示。
