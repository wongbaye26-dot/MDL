# EmoMusic v3.23.0 修复说明

> 版本 **3.23.0** / versionCode **303**

## 刮削后歌名变成文件名
- 实测文件里出现 `TITLE=一了百了 - 谢霆锋.flac`；
- 原因：刮削把已经变成文件名的曲库歌名写进了 TITLE；
- 修复：搜索/写入前去掉扩展名并拆出纯歌名；若曲库歌名像文件名，顺手写回干净歌名。

## 歌曲信息不更新
- 扫描 FLAC 时直接解析文件头 `LANGUAGE/DATE/GENRE`，恢复曲库字段；
- 写文件后刷新 MediaStore contentUri，避免旧 id 播放失败；
- 扫描重建条目继承旧字段。

## 语言
- 默认中文标签改为 **普通话**；
- 粤语仍按歌词粤语用字判断。

## 刮削速度
- 从串行改为 **4 路并发**；
- 歌词超时 8s → 4s。

## 已知限制
- 年份/风格依赖音源搜索结果，部分歌源站不给，仍为空；
- 后台运行尚未实现（需前台服务）。
