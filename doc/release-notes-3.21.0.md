# EmoMusic v3.21.0 发行说明

> 版本 **3.21.0** / versionCode **296**

## 本地歌曲信息
- 新增 `language / year / genre` 元数据；
- 扫描时读取文件标签里的年份/风格/语言写入曲库；
- 歌曲信息页新增「语言 / 年份 / 风格」可编辑字段，保存到曲库；
- FLAC 同时写 DATE / GENRE / LANGUAGE 扩展标签。

## 标签刮削
- 刮削更新标签时保留并回写曲库的年份/风格/语言。

## 本地音乐 6 个 tab
- 新增「风格」tab（位于「最近添加」前），按 `meta.genre` 分组，点进查看该风格歌曲；
- 6 个 tab 字号/间距/高度收紧，竖屏可完整显示。

## 播放器按语言自动处理
- 语言为粤语：自动开启粤拼；
- 语言为外语（英文/日文/韩文等）：自动开启歌词翻译；
- 国语/普通话：关闭粤拼与自动翻译。
