# v3.9.10 发布说明

> 版本 **3.9.10** / versionCode **201**

## 表头玻璃一体化
- 本地音乐：页头 + 页签 + 排序/筛选/选择工具栏改为**单一 LiquidGlass 背景**，不再各画一层；
- 排行榜、歌单广场：下方筛选胶囊行改为 `flat` 玻璃（只保留模糊+色调，去掉重复顶部高光/描边），与页头衔成一片；
- 歌单详情介绍卡保持玻璃材质。

## 收藏页 4 标签
- 改为统一分段式胶囊：歌单 / 收藏 / 试听 / 新建歌单；
- 新建按钮改为弱化 tonal 样式，避免和选中态混淆。

## 设置页壳层
- 设置首页 8 个分类改为统一两列入口卡（图标 + 标题 + 摘要）；
- 子页头增加分类说明文字；
- 分组卡片统一圆角/间距/图标底。

## 说明
本版设置页完成的是**首页与子页壳层/视觉结构**重构；设置项内部仍是原有组件。要做到完全不复用旧设置项组件、逐项重写，需要下一轮按分类逐个迁移（工作量约 90 项）。
