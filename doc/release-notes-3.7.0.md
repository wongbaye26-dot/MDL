# v3.7.0 发布说明

> 版本 **3.7.0** / versionCode **181**（arm64-v8a 包 181003、armeabi-v7a 包 181001）
> 目标平台 **Android 16（targetSdk 36）**，`minSdk 21`，只保留 `arm64-v8a` + `armeabi-v7a` 两个 ABI。

本次针对你反馈的 4 个问题逐项修复/更新：

---

## 1. 多音源下载：曲库、专辑封面、重扫找不到

**修复内容**

- 下载完成后由原生 `MediaScannerConnection` 主动把文件交给系统媒体库（只扫 `/storage/` 公共路径，跳过 `Android/data`、`Android/obb` 与 SAF 临时缓存目录），MediaStore 立刻能查到新文件。
- 本地音乐扫描改为「**目录直读 + SAF 枚举 + MediaStore**」三路按真实路径合并：
  - 有「所有文件访问权限」时直接列目录，刚下载、系统还没索引的文件也能扫到；
  - SAF 授权目录继续用文档树枚举；MediaStore 只用来补标题/专辑/封面等元数据。
- 新增「**待扫描确认**」暂存区：下载完成时直接插入曲库的条目，即使下一次整库扫描暂时没扫到，也不会被扫描结果覆盖掉（文件确实不存在时才清理，`content://` 条目 7 天 TTL）。
- 写标签/封面失败不再静默吞掉：`writeTaskExtras` 每个目标单独 try/catch + 日志，封面下载失败重试一次并校验非 0 字节；`addLocalMusicFile` 失败记录日志并重试两次。
- 封面三级兜底：**内嵌封面 → 本地封面缓存（下载到应用缓存目录，飞行模式也能显示）→ 在线搜索**（复用歌名/歌手匹配打分），保证本地曲库条目有可用封面。
- 已知边界：升级前已经下坏的旧文件（扩展名为 `.flac`、内容其实是 mp3）不会自动改写，重新下载一次即可；SAF 目录里的成品文件不做改格式操作。

## 2. 多音源：在线播放/下载自动切换音源

**修复内容**

- 换源不再要求备选音源「必须有和请求完全相同的音质」：按候选音源**实际支持的音质**选档（优先同级、下载只降级不升、播放可降级后升级兜底），因此「原源无损、备选只有 320k」也能成功切换。
- 换源成功后统一落定 **实际音源 / 音质 / 扩展名 / 文件名 / 路径**：修复「`.flac` 文件实际是 mp3」、下载中心音质标签与实际不符等问题；换源/重试时清理旧文件与 `.part`。
- 空结果不再进缓存：一次网络抖动后同一首歌仍能在本次会话里继续换源。
- 播放层拿到解析结果后回写 `toggleMusicInfo` 与实际音质 `playQuality`，并 Toast 提示「歌曲换源: 音源名」，下次播放直接走可用音源。
- **新增播放失败自动换源**：ExoPlayer 报 `PlaybackError`（CDN 404/403/链接过期/源站错误页）时——第 1 次自动刷新播放地址重试，第 2 次强制换到其它音源重试，两次都失败才交给界面报错；播放成功即复位重试状态。
- 下载内容与所选音质不符时（例如选了 Hi-Res、源站实际返回 mp3）：先重新解析地址/换源重试最多 2 次；仍不符则按**真实容器格式**改名并重写音质/标签/封面（如 `.flac` → `.mp3`，任务显示 320k），错误页/HTML 一律按失败处理、绝不入库。

## 3. 设置首页 8 大分类卡片 + 独立音源管理

**设置首页**改为 8 张统一大卡片（2 列 × 4 行，实时摘要）：

1. 音源管理
2. 基础设置
3. 播放设置
4. 下载设置
5. 搜索与列表（原「搜索」「列表」合并，旧设置项自动迁移）
6. 音乐工具
7. 其他设置
8. 关于

横屏左侧导航同步为这 8 项；竖屏子页/侧滑返回/返回键行为保持不变。

**音源管理**（独立整页）包含：

- 顶部汇总：可用音源数、支持的最高音质、上次检测时间、当前源初始化状态；
- 当前音源卡：状态灯、名称、版本、作者、说明、主页、「重新初始化」；
- 自定义源列表：启用 / 停用 / 删除（二次确认）/ 允许更新弹窗 / 在线链接或本地 `.js` 导入 / **检查更新**（在线导入时记录 `importUrl`，重新拉取脚本比对 `@version`，显示有新版本、已是最新、本地导入无法检查、网络失败，并持久化上次检查时间）；
- **音源质量矩阵**：每个音源支持的全部音质 + 最高音质高亮（初始化上报数据，切换源后自动刷新）；
- **音源音乐质量（实测）**：默认探测歌「晴天 周杰伦」可改；对每个音源实际搜索 → 按音质取播放地址 → HEAD/Range 探测（可用性、content-type、大小、推断码率、耗时），并发 2、单源失败隔离、可取消，结果可复制/写日志。

## 4. Android 16 目标 SDK / ABI / 密度 / 分屏小窗 / 品牌兼容

- **targetSdk 29 → 36**（compileSdk 36、minSdk 21），并按 Android 16 行为变更补齐：
  - edge-to-edge 强制生效：底部导航栏 inset 作为根内容 padding，随分屏/小窗/手势↔三键导航动态更新；
  - 预测性返回：显式 `enableOnBackInvokedCallback="false"` 保住现有返回栈（后续版本再迁移）；
  - targetSdk 34+ 前台服务：播放服务声明 `foregroundServiceType="mediaPlayback"`，补 `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MEDIA_PLAYBACK` / `POST_NOTIFICATIONS` 权限；
  - 修复 react-native-track-player 2.1.2 在 targetSdk 31+/34+ 下的两处崩溃：`PendingIntent` 补 `FLAG_IMMUTABLE`、`startForeground` 带类型并 try/catch 兜底；
  - 动态注册广播补 `RECEIVER_NOT_EXPORTED`（`UtilsModule` / `Lyric`）。
- **ABI**：只保留 `arm64-v8a` + `armeabi-v7a`；universal 包也只含这两个 ABI（体积 31MB → 20.7MB）。
- **屏幕密度**：补齐 120 / 160 / 240 / 320 / 480 / 640 六档（新增 ldpi 启动图与图标，`aapt` densities 已含全部六档）。
- **分屏/小窗动态响应**：原生 `getWindowInsets()` + 窗口尺寸事件 + JS 侧窗口尺寸三路刷新；修复「键盘弹起被误判为横屏/小窗」导致页面被重建的问题（见下）。
- **品牌兼容**：设置 → 其他 → 「设备与权限」集中展示通知权限/所有文件访问/电池优化/自启动状态与一键跳转；按小米/红米、华为/荣耀、OPPO/一加/realme、vivo/iQOO、三星、魅族给出后台保活提示，系统页打不开时回落应用详情页，不会崩溃。

## 真机验收后补充修复（P1）

真机（Samsung SM-S938B / Android 17）验收发现并已修复：

1. **targetSdk 36 下搜索输入框不可用**：键盘弹起时窗口/布局高度被临时压小（891dp → ~205~548dp），被 `isHorizontalMode` 误判为横屏/小窗，Home 切换布局导致搜索页被卸载。修复：`windowSizeTools` 识别「输入法临时压缩」（IME inset / 全屏下宽度不变且高度骤减）并忽略，`SizeView` 键盘期间不重算 `statusbarHeight`；键盘弹出时收起底部胶囊导航，避免浮在键盘上遮挡内容。
2. **下载 Hi-Res 实际是 mp3 却命名 `.flac`**：新增文件头嗅探与格式纠正（见上文第 2 点），并保证标签/封面写入使用修正后的真实路径。

## 已知限制

- 16KB page size：RN 0.73 预编译 `.so` 仍是 4KB 对齐，个别 16KB 页大小的 Android 16 设备可能无法加载原生库（需升级 RN 0.79+ 才能根治，本次不做）；本机实测设备 PAGE_SIZE=4096 正常。
- universal 包的 versionCode 为 181，低于 ABI 分包（181003/181001），不能直接覆盖安装已装的 ABI 包，只能全新安装或 `adb install -r -d`。
- 窄窗（如 800×1200 / 320dpi 模拟）下播放器页歌词与标题有轻微重叠（P2，后续优化）。
- 预测性返回 opt-out 是官方临时手段，未来 Android 版本会移除，需后续迁移到 `OnBackInvokedCallback`。
- 升级前已下载的「扩展名与内容不符」旧文件不会自动修复，重新下载即可。
