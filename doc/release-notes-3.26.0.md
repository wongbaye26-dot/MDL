## 新增 QQ 专辑元数据
- 按 QQ 搜索结果 `albumId` 请求专辑详情：
  - `aDate` → 年份；
  - `genre` → 风格；
  - `lan` → 语言（国语→普通话、粤语→粤语、英语→英文、日语→日文、韩语→韩文）。
- 语言优先用专辑 `lan`，比歌词判断更准，粤语识别会明显改善。
- 请求 4s 超时，失败不影响其他字段。
