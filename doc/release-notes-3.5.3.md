# v3.5.3 发布说明（2026-11-03）

本轮按用户反馈做两件事：

1. 本地音乐列表「更多菜单」按 **飞牛音乐**（com.trim.music）风格重做，并补齐 **歌曲信息查看 / 编辑**；
2. **音乐工具**功能加强 + UI 重构（曲库体检 / 歌词补全 / 无效条目清理）。

> 参考实现：本机安装的「飞牛音乐」1.0.3 的列表更多菜单与「歌曲信息」页（截图对照见 `.tmp-verify/feiniu/`）。

---

## 1. 本地音乐「更多菜单」：对齐飞牛音乐

点击行尾 ⋮ 或长按整行，现在会弹出**底部 Sheet**（不再是小浮层菜单）：

- 遮罩 50% 黑 + Sheet 上滑动画（240ms），顶部圆角 24；
- 顶部：封面 + 歌名 + 歌手；
- 三个白色操作卡：**播放 / 下一首播放 / 加入播放列表**（「下一首播放」会插到稍后播放列表头部）；
- 白色圆角操作行：**专辑：xxx**（点进专辑详情）、**歌手：xxx**（点进艺人详情）、**收藏/取消收藏**、**添加到歌单**、**歌曲信息**、查看所在目录、从列表移除、删除文件（红色）；
- 中性命名的浅色/深色两套配色（`#F3F3F3 / #FFFFFF / #111`，暗色 `#111113 / #1C1C1E / #F2F2F2`），不跟主题主色跑，保证和飞牛一致。

## 2. 歌曲信息：查看 + 编辑（对齐飞牛「歌曲信息」页）

菜单里点「歌曲信息」进入全屏页：

- 圆形返回、居中标题、圆形保存按钮（有改动才点亮）；
- 大封面（圆角 24）+ 码率 / 采样率 / 时长三列统计卡；
- 文件信息卡：文件位置（可换行）、文件大小、添加日期；
- 可编辑字段：**名称 / 歌手 / 专辑** 输入行；
- FLAC 额外支持 **年份 / 曲目序号 / 光盘序号 / 风格**（从文件标签读取，保存时写回；纯 JS FLAC 写入，保留封面与音频帧，写坏可回滚）；MP3 等格式这些字段不显示（文件标签能力暂不支持）；
- 保存：先写文件标签（SAF content:// 走原生写入），再写回曲库，列表立即刷新；失败会提示且不会出现「界面显示已改、文件没写」的脏数据。

## 3. 音乐工具：功能加强 + UI 重构

- **曲库体检**（顶部 hero）：总歌曲 / 总大小 / 缺封面 / 标签待补 / 缺歌词 / 无效条目，进入页面自动扫描（带进度），可一键重扫；改为「只读扫描」，不再边扫边写曲库，避免几百次列表重渲染。
- **封面修复**：统计来自体检；支持「文件里其实有封面、只是曲库地址失效」的自愈写回。
- **标签刮削**：保留原有能力（歌名/歌手/专辑写入文件 + 曲库），UI 并入新卡片体系。
- **歌词补全**（新）：检测真实路径旁缺失的同名 `.lrc`，批量读取内嵌/缓存/联网歌词后写成同名 `.lrc`（SAF 文档 uri 走原生同目录写入），进度、可停止、汇总（写入/未找到/失败）。
- **无效条目清理**（新）：曲库里文件已经不存在的条目，一键从曲库移除（**不删磁盘文件**）；判断时要求父目录可读，避免没权限时把整库误判成无效。
- UI：曲库体检 hero + 分区卡片（卡片头/说明/数量 badge）、统一圆角 16 卡片、主次按钮、进度条、汇总 chip、带封面的预览列表、空态；深浅主题都适配。
- 批量任务之间互斥，一次只跑一个。

## 升级注意

- 覆盖安装请用 arm64 包；universal 包 versionCode 是裸号，低于已装版本，只能全新安装。
- 歌曲信息保存、补封面、刮削标签、补歌词都会改写用户文件/新增 .lrc，属功能行为；公共目录不允许写时会降级为「只更新曲库」（封面/标签）或提示失败（歌词）。
