# EmoMusic v3.51.1 发布说明

发布日期：2026-11-09

## 批量操作条 UI 重做

新增共用组件 `BatchActionBar`，本地音乐与下载中心统一：

### 位置
- 批量模式下通过 `useOverlayLock` 收起底部胶囊导航；
- 操作条停靠在底部（bottom 14、高 64、圆角 22），与胶囊导航同一位置，不再出现
  「操作条浮在列表中间 + 下面还有一层导航」的双层底栏。

### 布局
- 左侧固定「已选 N」，中间操作按钮等分，右侧单独关闭按钮；
- 「已选 2」不再被挤成竖排，标签不再挤在一起；
- 常驻操作精简：
  - 本地音乐：队列 / 歌单 / 隐藏 / **更多**
  - 下载中心：全选 / 暂停 / 继续 / **更多**
- 危险操作收进「更多」ActionSheet：
  - 本地音乐：删除文件到回收站、从曲库移除（红色）；
  - 下载中心：移除任务（不删文件）、删除已完成文件（红色）。

### 视觉
- 统一圆角/描边/阴影；入场 200ms 上浮 + 淡入，和 App 其它浮层动效一致。

## 版本

- versionName `3.51.1`，versionCode `352`（arm64 包 `352003`）
