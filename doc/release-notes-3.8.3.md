# v3.8.3 发布说明

> 版本 **3.8.3** / versionCode **185**（arm64-v8a 包 185003、armeabi-v7a 包 185001）
> Android 16（targetSdk 36），`minSdk 21`，ABI 仅 `arm64-v8a` + `armeabi-v7a`。
> 本版按你反馈的 3 点更新。

---

## 1. 来源音源改为 Material You 单色品牌矢量图标（去掉小胶囊卡片）

- 排行榜 / 歌单广场 / 搜索页的来源行不再显示「小蜗音乐 / 小枸音乐 / 小秋音乐 / 小芸音乐 / 小蜜音乐」文字，也不再有小胶囊卡片，只显示对应的品牌**单色矢量 LOGO**：
  - **酷我音乐**：粗体圆头「K」+ 八分音符；
  - **酷狗音乐**：狗头剪影（立耳 + 圆脸，眼睛鼻子镂空）；
  - **QQ音乐**：官方双音符 ♫（两个符头 + 符干 + 倾斜符杠）；
  - **网易云音乐**：云朵剪影 + 云内音符；
  - **咪咕音乐**：圆拱「m」波形。
- 全部单色（Material You）：**当前音源用主题主色**，其它用次级灰色（`c-450`）；不画品牌彩色底、不画背景、不画描边。
- 点击热区仍有 34/38dp + hitSlop，按压有透明度反馈；无障碍朗读仍是原音源名、含选中状态；未识别的自定义音源回退显示文字，不会被裁剪。

## 2. 设置列表 UI 放宽并与子设置页样式对齐

- 设置首页从「一张紧凑卡 8 行」改为 **3 张 Section 卡**，直接复用子设置页的 Section 组件，卡片圆角/描边/底色、组标题、行间分隔线、组间距都与子页完全一致：
  - **播放与下载**：播放设置 → 下载设置
  - **内容与工具**：音源管理 → 搜索与列表 → 音乐工具
  - **系统与关于**：基本设置 → 其他 → 关于
- 行内数值放宽：行高 60 → **72dp**、左右内边距 **16dp**、图标 36 → **40dp**（icon 20）、图标与文字间距 12 → **15dp**、标题 14.5 → **15sp**、chevron 18；摘要仍实时、单行省略。
- 横屏左侧导航同步放宽：行高 46 → **54dp**、图标 28 → **32dp**、图标与文字间距 12；8 项超出时可滚动，顺序与竖屏一致。

## 3. 首页搜索按钮 + 热门搜索文字对齐

- **首页搜索按钮**按 Material You 优化：40dp 圆形 tonal 按钮（主色 10% 表面色）+ **48dp 触控热区** + MaterialIcons 圆头搜索图标；按下叠加 10% 主色 state layer（native driver 90ms 淡入淡出），替代原来整块变暗的按压；与本地音乐/下载中心/排行榜页头按钮同色调、仅 2dp 尺寸差，歌单广场页头按钮同步变为 40dp。
- **热门搜索胶囊文字改回靠左**：序号 + 热词左对齐（普通模式左内边距 10dp、紧凑模式 8dp），超长才省略号；垂直居中规则保留。历史搜索胶囊、来源筛选、紧凑键盘态布局、点击行为等其它不变。
